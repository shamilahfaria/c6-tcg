# Gauntlet TCG — Game Week

Cohort 6 as a Pokémon-style trading card game. Every cohort member is a card; types, attacks and flavor text come from what people actually do.

- **Play:** open `tcg/index.html` (no build, no server — works from `file://`).
- **Cards:** `tcg/cards.js`. Photos in `tcg/photos/<id>.jpg`. Logic in `tcg/battle.js` (`node tcg/battle.test.js`).
- **Holo effect:** `tcg/holo.css`, vendored from [simeydotme/pokemon-cards-css](https://github.com/simeydotme/pokemon-cards-css).
- `rage/` is a second prototype (Level Devil-style platformer where every trap is an AI failure mode). Playable, not the submission.
